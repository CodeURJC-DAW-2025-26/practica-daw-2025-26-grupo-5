La ETSII ha preparado un servidor para el desarrollo de tu práctica

El fichero zip contiene lo siguiente:
* Este fichero leeme.txt
* Una carpeta ssh-keys/ con la clave privada que te permite acceder al usuario vmuser

La dirección 10.100.139.140 está dentro de la VPN de la universidad, así que deberás
lanzar el cliente globalprotect si quieren conectar desde casa.

En tu caso, deberías poder acceder a la máquina como alumno con el comando:

ssh -i ssh-keys/appWeb05.key vmuser@10.100.139.140

o bien

ssh -i ssh-keys/appWeb05.key vmuser@appWeb05.dawgis.etsii.urjc.es

Es posible que la primera vez que te conectes recibas un mensaje de advertencia
diciendo que la máquina es desconocida. Esto es normal y deberás teclear "yes" para
continuar con la conexión.

Si quieres evitar tener que teclear el comando anterior, puedes guardar la
configuración de la máquina en el fichero .ssh/config de tu PC de escritorio.
Edita el fichero <<tuUsuario>>/.ssh/config para añadir las líneas:

Host appWeb05 10.100.139.140
   Hostname 10.100.139.140
   User vmuser
   IdentityFile appWeb05.key

y copia el fichero appWeb05.key desde la carpeta ssh-keys a tu carpeta <<tuUsuario>>/.ssh/

de forma que ahora podrás conectar directamente usando el comando:

ssh appWeb05

También deberías ser capaz de conectar Visual Studio Code directamente con tu 
servidor usando la extensión "Remote SSH" o "Remote Explorer".

Dado que el fichero appWeb05.key actua como contraseña para acceder a la máquina, debes
poner especial cuidado en protegerlo frente a filtraciones o pérdidas.

Recuerda que debes emplear este servidor de forma exclusiva para el desarrollo de 
tu práctica. El uso de la máquina para otros fines (como compartición de ficheros o 
minado de criptomonedas) conllevará la expulsión del sistema y puesta en conocimiento 
de la dirección de la ETSII.

Os deseo buena suerte con el trabajo a realizar.

Un saludo.
